## MỤC 2: HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN
- **Các bước cài đặt:**

1. Mở SQL Server Management Studio (SSMS), chạy file `Database/ScriptDB.sql` để khởi tạo CSDL và dữ liệu mẫu.
2. Mở file `.sln` bằng Visual Studio 2022.
3. Mở file cấu hình (`App.config` hoặc `DatabaseHelper.cs` / biến `connectionString` trong từng file code), sửa lại chuỗi kết nối ConnectionString cho phù hợp với máy cá nhân.
4. Build & Run dự án (F5).
